# Картинки сайта

`index.html` ждёт здесь иллюстрации в формате WebP (экспорт векторов из `source/Frame_27.svg`):

- `breaking.webp`
- `tower.webp`
- `anatomy.webp`, `anatomy-dots.webp`
- `styles.webp`
- `usage.webp`
- `symbols.webp`, `symbols-dots.webp`
- `author.webp`

Положите файлы в эту папку, имена должны совпадать с именами в `index.html`.
